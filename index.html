[01] Waterworth · 2025–present

The documents nobody could read

Decades of municipal records, every page scanned as an image. No text layer, no structure, nothing a machine could parse. Clients wanted to query all of it like a database. I build and own the pipeline that makes that possible.

why this is harder than OCR plus an LLM call
  • Everything starts as pixels. With no text layer the pipeline has to begin at layout and region detection, and anything it gets wrong there poisons every stage after it.
  • Bylaws love borderless tables. Rows separated by whitespace alone defeat parsers that key on ruling lines, so structure gets recovered geometrically with Hough transform and Otsu thresholding.
  • Partial credit does not exist. An entity pulled correctly but filed under the wrong section still reads as correct to a user, which makes confidently wrong answers the failure mode worth engineering against.

what is mine and what is the team's
  • Mine, end to end: document vision, LLM extraction, ensemble validation, Airflow orchestration on Kubernetes, plus the per-concept evaluation harness and release gates that catch regressions before they ship.
  • Throughput work: batched file processing and per-pod memory tuning.
  • The client-facing product is built by the wider team on top of my pipeline's output.
  • The result I care about is not an accuracy number. It is that the people who understand the documents can now run an ingest without an engineer in the room.

[02] Avid Technology · 2024–2025

Searching sound with words

A sound library is only as findable as its filenames. If nobody happened to describe the thing you need in the words you would use, it may as well not be in there. So we taught it to answer questions instead.

+19%audio tagging accuracy
3services shipped to product teams
the two problems underneath it
  • Audio has no natural index. Text search works because text is already symbols. Audio is a waveform until a model says otherwise, so retrieval quality is capped by the encoder before a single query runs. I fine-tuned CLAP and Qwen-Audio to raise that ceiling.
  • Nobody agrees what a sound is. Whether a tag is right is a judgement call, which means you cannot claim improvement until you have decided what improvement means. I defined and tracked the metrics first. The 19% is measured against those.

[03] ASL Environmental Sciences · 2022–2024

When labels cost more than GPUs

Echograms can only be read by marine biologists, and there are very few of them. Every label came out of scarce expert time, so the usual answer, train on more data, was simply not available. Four papers and a thesis came out of working around that.

−75%biologist analysis time
4peer-reviewed publications
what the constraint actually changes
  • You cannot buy your way out with data. When the labelling budget is the binding constraint, the problem stops being architecture search and becomes learning strategy.
  • Acoustic boundaries are genuinely fuzzy. Ocean phenomena do not have crisp edges the way objects in photographs do, so standard segmentation losses optimise for the wrong thing. I built boundary-aware and class-aware losses shaped to the data instead.
  • So make the labels cheaper, not more numerous. Semi-automatic labelling generated candidate ground truth that experts corrected rather than authored. Reviewing is far cheaper than drawing, and that single change is where most of the 75% came from.
the method, briefly
  • Two-step model pairing image classification with semantic segmentation.
  • U-Net, DeepLab, InceptionV3 and ResNet variants trained and compared on CUDA GPUs.
  • Three learning strategies targeting feature extraction, adaptive segmentation, and class-aware loss.

[04] Archipelago Marine Research · 2023

The model was never the problem

Detection on a working fishing deck: salt spray, bad light, a camera that will not hold still. I spent weeks on architectures. The accuracy came from rebuilding the annotation system instead.

84%detection accuracy
+70%data collection efficiency
what that actually looked like
  • Real-time detection models reaching 84% accuracy on genuine vessel footage, not a clean benchmark set.
  • Rebuilding the annotation system that fed them produced more gain than any architecture change I tried. It is a pattern I have now run into more than once.
  • MLOps alongside it: data pipelines, model versioning, and deployment through Azure Machine Learning, MLflow, and CI/CD.
